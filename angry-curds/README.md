# 🧀 Angry Curds 🧀

A cheese-themed physics-based game inspired by Angry Birds! Launch cheese curds to destroy mice and knock down structures.

## How to Play

1. Open `index.html` in your web browser
2. Drag the cheese curd backwards on the slingshot
3. Release to launch it at the structures and mice
4. Destroy all the mice to win the level
5. You have 3 cheese curds per level

## Game Features

- **Physics-Based Gameplay**: Powered by Matter.js for realistic physics
- **Multiple Levels**: Progressive difficulty with more complex structures
- **Cheese Theme**: Everything is cheese-themed for a fun twist
- **Score System**: Earn points for hitting targets and clearing levels
- **Responsive Design**: Works on different screen sizes

## Controls

- **Mouse Drag**: Pull back the cheese curd on the slingshot
- **Mouse Release**: Launch the cheese curd
- **Restart Button**: Restart the current level
- **Next Level Button**: Proceed to the next level (appears after winning)

## Scoring

- Hit a mouse: 50 points
- Mouse falls off screen: 100 points
- Hit a structure block: 10 points
- Level completion bonus: 500 points
- Unused curds bonus: 100 points each

## Technologies Used

- HTML5 Canvas
- CSS3
- JavaScript (ES6+)
- Matter.js (Physics Engine)

## Game Mechanics

The game uses realistic physics simulation with:
- Gravity
- Friction
- Collision detection
- Elastic collisions (restitution)
- Density-based weight distribution

Enjoy destroying those pesky mice with your cheese curds! 🎯
